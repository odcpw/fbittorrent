## P0-14 — Private store permissions

Bead `fbt-p0-14-rsx`; branch `ntm/fbittorrent/cod_4-p0-14-rsx`, cut from local
main at `70476b1`. The previous P0-11 branch is unchanged. The orchestrator
explicitly extended this bead to `LegacyMigration::save` and its unit test;
the main.rs changes are confined to that writer and its adjacent test module.

Shows, default config creation, live and parked engine ledgers, torrent
metadata, engine diagnostics and migration snapshots now enforce mode 0600
before writing/renaming. Existing 0644 engine/migration temporaries are chmod'd
through their open descriptor before any new private content is written.
Shows/RSS/search lock files are created as 0600 and existing lock files are
repaired on save. Config defaults use the same atomic writer as later saves.
Search writes and the final provider-install rename now fsync their directory;
engine metadata and diagnostics use the same durable writer as the ledger.

All writers retain temp-file write, file fsync, atomic rename and directory
fsync. Existing merge/lock behavior and fixed engine temporary paths used by
persistence-failure tests are preserved. Errors in chmod or fsync propagate.
This change does not rewrite existing user stores eagerly; modes are enforced
when each writer saves. No installed data, torrents or services were touched.
