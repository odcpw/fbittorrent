## P0-11 — Truthful peer labels

Bead `fbt-p0-11-tjs`, branch `ntm/fbittorrent/cod_4`. Implementation checkpoint
`a894543`; P0-15 imported with the explicitly authorized merge `a485d05`.
All three acceptance criteria, the selected native case and the full local
gate pass. CI/main verification and bead closure remain with the orchestrator.

Native torrent details now say `N peers connected`, using the existing native
peer total in `num_leechs`. Legacy mode sums its connected seeds and leechers
for the same label. The widget drops its fabricated seed suffix. Contract
1.1.1 documents the unchanged numeric native seed sentinel with the exact note
`always 0 in native mode: unknown` and a `changes[]` entry for
`list[].num_seeds`.

YTS JSON retains missing/null counts as `None`, mapping them to the existing
Nova-compatible SearchResult unknown representation. Rows leave unknown
count columns blank and details omit unknown terms. Real provider zeroes and
positive counts remain visible. This does not introduce the future API's
optional `seeds` field or change engine accounting. The five wide golden
changes deliberately update only the label and its exposed tail behind the
help modal; no golden was regenerated wholesale.

### Retained failures and limits

The first unit run passed 133 tests and exposed the wide help modal's changed
label tail. Only that expected golden fragment was corrected; all 134 then
passed (`unit.{jsonl,log}` and `unit-fixed.{jsonl,log}`). The initial actual
wrapped release build passed in 1m 17s; its e2e draft sent Down before results
arrived. Waiting for the result and requiring selected details fixed the test
sequencing without changing its assertions or ten-second bounds
(`selected-initial-failed.*`, `selected-native-initial-failed/`).

One retry lost its TUI during an existing RSS prerequisite before the new case;
stderr was empty and the cause is unproven (`selected-prerequisite-failed.*`,
`selected-native-prerequisite-failed/`). Subsequent selected and full runs both
passed. Terminal streams are now retained for diagnosis. Earlier scope setup
and cancelled queued attempts are retained as `build-case-scope-setup-failed.*`
and `build-case-requeued.*`; neither ran application tests.

The first combined selected/gate run passed the new case but exposed a gate
integration issue: its synthetic early-abort fixture copies all.sh without the
new plugin lint file. Running lint before the intended release abort changed
exit 137 to 127. Lint now runs after the release build, before native.py; the
normal gate still requires it and the synthetic test and assertions are
unchanged. Failed evidence remains in
`selected-and-gate-lint-integration-failed.*` and
`gate-lint-integration-failed-fbtlog_test/`.

No acceptance criterion remains unmet. CI/main verification, live desktop
qualification and public YTS behavior are not claimed by this local gate.
The earlier unexplained prerequisite exit is a follow-up if it recurs; no
out-of-scope runtime change or new bead was made.
