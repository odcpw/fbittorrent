### Exact guarantee and permitted explicit launches

The guarantee covers **every automatic widget path and every torrent action**:
status polling and refresh, the removed reconcile timer and the native reconcile
stub, start, stop, remove/delete, open a torrent, seeding changes, and adds.
They cannot start the torrent app. A closed-app torrent action returns the
closed-engine refusal instead of opening a terminal.

Within the widget, the only launch-capable path is
`Panel.qml::openTui()` -> `root.bar.run(tuiCommand)` ->
`omarchy-launch-or-focus-tui ... fbittorrent tui`. The user's explicit
**Open TUI** requests remain permitted to launch the app in today's architecture:

| Explicit entry point | Route to the permitted launcher |
|---|---|
| Middle-click on the bar icon | `BarIconButton.onPressed(Qt.MiddleButton)` -> `root.openTui()` |
| `t` or `T` in the panel | `PanelKeyCatcher.onTextKey` -> `root.openTui()` |
| TUI header button, including keyboard activation | `HeaderAction` index 1 `onClicked`, or `activateHeader()` with index 1 -> `openTui()` |
| The panel's `tui()` IPC method | `IpcHandler.tui()` -> `root.openTui()` |

This exception is deliberate; this bead does not remove or change those features.
The daemon split will change their lifetime later. Ordinary CLI commands outside
the widget also retain their documented startup behavior unless `--no-start` or
`FBITTORRENT_NO_START=1` is active.

Source-route audit:
`target/test-logs/fbt-p0-07-563/review-launch-routes.log`. `Service.qml` contains
no `openTui`, `tuiCommand` or bar launcher call. Every torrent action uses
`runAction()` -> `pump()` -> `[bin, "--no-start"].concat(next.args)`; the status
process runs `[root.bin, "--no-start", "status", "--json"]`. The only remaining
service timer calls `refresh()`, which starts that status process. Action exit
callbacks refresh or pump the same restricted queue. In `Panel.qml`, automatic
open/row callbacks and torrent controls call the service methods; the launcher
call is confined to `openTui()` and the explicit entry points listed above.
