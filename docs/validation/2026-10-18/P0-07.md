## P0-07 — the widget never starts the app

Bead `fbt-p0-07-563`, branch `ntm/fbittorrent/cod_3`.
Implementation commit `10672b7`; dependency merge `626c101` includes P0-15's
shared logger and P0-17's engine-test fixes. The orchestrator owns verification
on `main` and bead closure; this work does not change the tracker.

### Behavior

- The widget no longer has a reconcile function or its 60-second timer. Its
  status poll and every queued action pass the global `--no-start` flag.
- Native `reconcile` returns exactly
  `{"ok":true,"touched":0,"note":"native scheduling is intrinsic"}` without
  connecting. Legacy reconcile retains its existing behavior.
- `--no-start` and `FBITTORRENT_NO_START=1` prohibit startup, including explicit
  `up` and `tui`. A closed engine produces typed exit 4, `code_name: backend`,
  and the hint `fbittorrent up`. The process-level restriction survives config
  reloads and does not alter the stored `autostart` preference.
- Widget `online` requires both `status.ok === true` and
  `status.running !== false`, so the widget stays hidden under the future
  stopped status shape. Contract 1.1.1 advertises `global_flags[]` and the
  environment variable; the README and printable handbook describe them.
