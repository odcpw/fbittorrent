### Changes and evidence boundaries

The loopback observer now waits for `ManagedTorrent::wait_until_initialized`
before interpreting `progress_bytes` as payload. In rqbit's `stats()` the
initializing state reports `checked_bytes`, whereas the live state reports
verified payload progress. The old observer could therefore mistake a full
initial hash scan for a 256 KiB transfer in about 0.1 seconds. Baseline diagnostics did not include the state enum, so this is a
source-supported diagnosis; fixed diagnostics now include state. The fixed
observer retains the exact stats sample with bracketing monotonic timestamps
instead of resampling after `block_on` returns. Both the partial-payload and
upload-cap assertions remain; the cap, 64 KiB observation threshold, 256 KiB
fixture, 15-second timeout, and `cap * (elapsed + 1.5)` allowance are unchanged.
The cap assertion runs first so the uncapped negative checks its failure
directly. Shutdown, restore, resume and exact-byte assertions are retained.

Both assertion diagnostics include observed bytes, payload length, elapsed
monotonic time, configured/effective admission limit, and observer timestamps;
fixed samples also include the engine state. `FBT-P017-STEP` records are
converted by the retained runner to Appendix E.1 JSONL steps. Failure to
acquire a test engine lock records its path, inode, PID and matching kernel
locks before panicking.

`InstanceLock` was already scoped to its lock-file directory. The claim that
independent directories share one process-wide lock was not reproduced.
However, a deterministic regression reproduced another way to get the same
busy error: a forked child retains the open file description until exec/exit,
so closing only the owner's descriptor does not release `flock`. Provider
spawns in parallel tests use fork/pre-exec and can overlap an engine restart.
`InstanceLock::drop` now explicitly unlocks before closing. The new tests
prove same-directory exclusion, independent-directory admission, and immediate
reacquisition while a forked child still holds an inherited descriptor.
This establishes the inheritance defect; it does not prove the uninstrumented
P0-15 failure had this cause.

All `src/engine.rs` changes are in its test module. The minimal production
lock change is in `src/ipc.rs`, where `InstanceLock` is defined; the restart
marching orders explicitly included the lock implementation. Merge P0-10
first as requested; this branch does not merge or rewrite its work.
