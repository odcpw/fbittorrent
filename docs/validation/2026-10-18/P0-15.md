### Changes

- `regression_tests/fbtlog.py` provides `Case`, timed step handles, optional
  assertion observations, `Case.popen`, per-case stderr slices, failure tails,
  suite summaries, forced failures and verbose JSONL output. Paths resolve from
  the module's repository, independently of the current directory. Each suite
  clears its previous logs on first use in a process.
- `regression_tests/native.py` converts the existing 11 scenarios to named
  cases, logs CLI results and asserted pane captures, and preserves all 49
  original application assertion conditions. Failed checks continue; unexpected
  exceptions produce a failed final record and let subsequent cases run.
  Polling captures are omitted by default, retaining the final asserted
  observation; verbose mode includes the polls and mirrors each JSONL line.
- `plugin/tests/qs-log.py` converts decorated `FBTQS-*` markers from merged
  process output, passes `NO_COLOR=1`, and includes the three-marker self-test.
- `scripts/testlog-summary.py` counts JSONL case verdicts, rejects failed
  intermediate steps even under a green final verdict, and reports the slowest
  five cases per suite. `all.sh` runs the logger and converter tests and invokes
  the summary last, including on earlier gate failures. Its background-panic
  scan remains enabled.

Here `regression_tests/` means
`agent_ergonomics_audit/audit/regression_tests/`.

### Execution details and follow-ups

`--case` replays prerequisite scenarios in the disposable shared fixture and
logs only the selected case; this is documented in `--help`. The native suite
uses isolated config, data, runtime, state and cache directories and a private
tmux server/session named for this bead. Literal keys use `tmux send-keys -l`.

The first remote umbrella attempt hit Unix-socket `SUN_LEN` errors in three
existing unit tests because the worker's TMPDIR was too long. `all.sh` now uses
a host-target runner setting `TMPDIR=/tmp` for test execution, retaining the
normal Cargo shim. The next remote unit run passed all 104 tests. The release
build then hit rch's 300-second build limit; `all.sh` now defaults its build
allowance to 1,200 seconds while honoring an explicit override. These failures
are retained as `all-remote-tempdir-failure.log` and `all-release-timeout.log`
under the bead's log directory.

The worker subsequently built the release successfully in 6m16s, but its local
artifact-delivery process was terminated with exit 143. The cause of that signal
was not established. The retry reported an unfinished overlapping source owner
and selected rch's permitted local fallback. That fallback built the worktree
release successfully in 12m22s, and the final normal and forced umbrellas both
ran successfully to their expected exits using the local fallback. Logs:
`all-artifact-termination.log`, `release-delivery-retry.log`, `all-normal.log`
and `all-forced.log` under the bead's log directory.

Follow-up for the orchestrator: investigate the worker's interrupted artifact
delivery / unfinished source ownership if it recurs. No shared worker state was
changed. Main/CI verification and bead closure remain with the orchestrator.
No acceptance criterion is unmet on this branch.
