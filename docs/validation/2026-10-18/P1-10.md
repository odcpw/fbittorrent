## P1-10 — Legacy socket adapter

Bead: `fbt-p1-10-zxk`. Branch: `ntm/fbittorrent/cod_2-p1-10-zxk`.

The daemon's existing engine.sock listener now sends every request through
`api::legacy`: one `EngineOp::parse`, typed execution in the running or parked
engine, and `EngineResult::to_legacy_json` / `TorrentView::to_legacy_json`.
The existing ipc::Server retains its four-byte big-endian framing, 32 MiB cap,
double-encoded value/error response envelope and joined request workers.
Parked torrent/file lists retain their historical Value member ordering, and
parked diagnostics retain the selected-interface wording and backend error.
Controls use the daemon owner's Lifecycle: shutdown requests Stop(Quit), and
restart requests Restart(Explicit). The existing supervisor consumes those
requests without replacing the listener, instance lock or process identity.

The authorized module registration is deliberately minimal: api/mod.rs contains
only its P1-05 handoff comment and `pub mod legacy;`; main.rs adds only `mod api;`.
An automated source comparison verifies that daemon/mod.rs outside dispatch is
unchanged, including slot replacement, lock, signal and quiesce ownership.
P1-05's contract, fixtures and IPC documentation are untouched. Dormant
seed/open/remove wiring remains with P1-16b following the retracted handoff.

Three new adapter unit tests cover all 22 current routes (printing route and
typed variant), serialized request fields and binary uploads, fragmented real
Unix frames and lifecycle controls, a pre-connected reader, and byte-for-byte
parked torrent/file/transfer responses against the existing facade. The socket
unit fixture checks control delivery, not a simulated engine restart; the real
restart is qualified by the unchanged daemon harness below.

All builds use the normal rch shim and CARGO_BUILD_JOBS=4. All executions use
private XDG directories; daemon fixtures additionally bind to loopback and
own disposable payloads, paths and process groups. Logs below are relative to
`target/test-logs/fbt-p1-10-zxk/`.
