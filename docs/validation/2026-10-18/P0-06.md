### Limits and follow-ups

The read-only billing probe returned HTTP 404 and identified a missing `user`
token scope (`availability/billing.json`). Actions minutes are **unverified**;
this is not evidence that Actions is unavailable. README requires the local
`all.sh` gate before every merge, including when hosted Actions cannot run.

The standalone review-round files were absent from the worktree and the cited
scratchpad location, and the initial commit `15d73df` reconstructed the tools
from the bead's stated checks. However, the round-2 `mockwidth.py` source is
embedded in `docs/plan-2026-10-18/review-log.md` (the Python source at lines
311–346). The initial implementation missed that source; the previous receipt
did not identify it. This revision uses that embedded script as the behavioral
reference, restoring its heading-scoped dimensions, rounded edges, per-block
width sets and overflow/ragged diagnostics.

The committed mockwidth remains an adaptation: it provides an optional default
PLAN path and reusable `check()` function, measures plain/text fences while
skipping Rust examples (14 blocks here versus 15 in the review transcript),
counts indented frame edges, excludes annotations beyond the right edge, and
adds malformed/unclosed frame and fence diagnostics. Its Unicode width helper
also treats combining characters and all `Cf`/`Mn` characters as zero width
rather than only combining characters and the review script's listed zero-width
codepoints. Explicit cells/columns/wide
headings remain accepted. The removed inferred width cap for undeclared blocks
now agrees with the review script: only a heading declares a terminal width.
`dagcheck.py` remains the reconstruction described above; it was not changed by
this follow-up.

Follow-ups: publish and verify the green-main/red-branch/artifact criteria;
observe the first hosted weekly audit; repair the existing ragged PLAN mockup
in an assignment that owns PLAN; investigate the intermittent idle RSS excess
and local-versus-RCH build comparability before treating resource acceptance as
stable. Neither the baseline nor the margin was changed to clear that failure.
Future daemon, API, QML and visual gates remain
in their named beads. No live widget, legacy service, VPN namespace or public
network acceptance is claimed here.
