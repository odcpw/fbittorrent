## P0-13 — Destructive confirms default to No

Bead: `fbt-p0-13-kdy`. Branch: `ntm/fbittorrent/cod_2`. Base: `5b94243`.

TUI remove, delete-files, unfollow and remove-feed prompts now accept only
`y`/`Y` (unmodified or Shift). Enter, Escape and other keys cancel. Labels
read `y/N`, the prompt body says `default: No`, and the footer reads
`(y) Remove` / `(Esc) Cancel`.

The widget's existing `d`/`D` and trash click now request an inline strip:
`Remove '<name>'? Files are kept.` followed by Cancel and Remove. Cancel gets
actual Qt focus. Enter/Space cancel; Escape cancels the strip. Only `y`/`Y` or
an explicit Remove click dispatches removal. The strip holds a copy of the
original hash/name, cancels if that hash disappears, and resets on popup close.
The new dynamic title uses `Text.PlainText` and is tested with markup-shaped
input. All rendering uses existing Omarchy components and style tokens.
